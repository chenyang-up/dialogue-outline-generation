# 格式契约单一权威 + 脱敏作为可选能力

格式契约（标题嵌套偏移、净结论分类口径、头部字段）**唯一收在模板**：`02_raw_log.template.md` 顶部注释承载嵌套偏移、`01_conclusions.template.md` 顶部注释承载分类口径，`references/design.md` 与 `references/output-format.md` 只留**指针**不再复述。这是对 ADR-0007"磁盘模板是唯一格式权威"的**贯彻彻底化**（不是新决策，是把已宣未立的规则落地）：旧版同一规则在模板注释、design.md、output-format.md 三处并存，改动必漏、高频返工（8 轮实测的漂移与围栏假红都源于此）。代价是模板注释变长，但执行者本就逐行读模板，"规则唯一"的收益大于注释长度代价；只收**格式类**，技能痕迹判定、路径回退、幂等等非格式行为仍在 references、不由模板承载。

**伴随的新增**：将**数据脱敏**作为一项**默认关闭、用户主动触发**的可选能力引入（v4.1.0）。默认逐字保真（守住"逐字保留"契约）；仅当用户在触发指令明确说「脱敏」「mask」才启用，对明确敏感项（邮箱、密钥、真实人名等）在原位写 `[脱敏:类型]` 并换成占位符，保留可解释痕迹、不静默删，三份产物一致。它延续了既有"有节律地不逐字、但必须可解释"的机制（同「混合轮拆分」「工具结果退化摘要」），并为落盘前自检引入唯一新的合法"非逐字"例外。默认 off 意味着不改变任何既有行为，故版本 **4.0.0 → 4.1.0**（minor，非破坏性）。未决/配套：`.acceptance/` 开发侧验收（含"编号重排"合成 fixture 与断言脚本）是验证以上规则的手段，属 CI 回归，不进技能运行路径。
