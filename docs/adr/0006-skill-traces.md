# 技能痕迹不入产物

本技能自身的触发指令、执行过程、落盘回执与交互回答（**技能痕迹**）一律不进流水、净结论与交接文档；被剔空的主题在两份文件里一起消失、编号重排；剔除是静默的，不留占位行；整场对话除技能使用外无内容时直接拒绝归档、不产出任何文件。这样做是因为归档是给人读、给下游 agent 读的**历史快照**，而"为了把对话落盘"而产生的文字对读者没有信息价值，却会随每次重跑自我复制——同一场对话实测四次重跑，流水从 12.3 KB 单调涨到 25.8 KB，增长的正是上一轮的落盘回执；判据只取"内容是否由使用本技能这一动作产生"这一条，是因为把界限划在"是否提到本技能"会误伤真正的设计讨论，而那恰恰是最该留存的内容。代价是产物不再是"对话的完整副本"（流水从"逐字保留"变成"逐字保留减去技能痕迹"），且混合轮——一轮里既回答归档提问又夹带实质内容——需要逐句拆分判断，存在主观误差；同时**修订**了 `references/output-format.md` 早期"主题标题始终保留"的绝对表述：成立但无净结论的主题仍保留，被剔空的主题则根本不成其为主题。
