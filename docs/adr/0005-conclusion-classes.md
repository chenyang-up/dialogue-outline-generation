# 净结论按内容类型分四类，「未决」降级为条目标记

`01_conclusions.md` 的净结论按**内容类型**分为事实、决策、约束、待办四类，顺序固定为「事实 → 决策 → 约束 → 待办」，取代原先固定的「决策 / 约束 / 未决」三类；未决项不再是独立类别，改为条目行首的 `[未决]` 标记，可出现在任意类别下，类别标题按需保留而主题标题仍无条件保留。这样改是因为分类轴应从"是否已定"换成"这是什么"——「未决」描述的是条目的状态而非内容类型，与内容类别平级会迫使同一条信息在归属上二义；同时新增的「待办」补上了 `00_handoff.md` 的「推荐下一步」一节此前没有净结论出处的契约漏洞。代价是分类需要逐条判断、四类之间偶有歧义（靠 `references/design.md` 的「跨类都拿不准时，归入它一旦落定后所属的类别」规则收敛），且这**修订了 spec 的 User Story 11**（原要求可区分三类）——其"一眼看到哪些事还没落地"的意图由 `[未决]` 标记继续承载，被推翻的只是固定三类的枚举。
