# Triage Labels

本仓库沿用五个规范的 triage 角色，标签字符串与角色名一致——没有做重命名映射。

| 标签 | 含义 |
| --- | --- |
| `needs-triage` | 需要维护者评估该 issue |
| `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | 已完整规格化，可交给离线 agent 执行 |
| `ready-for-human` | 需要人工实现 |
| `wontfix` | 不予处理 |

当某个 skill 提到某个角色时（例如"打上 AFK-ready 标签"），直接使用上表对应的标签字符串。
